# One More · Privacy Policy

**「One More」(一局)** 的隐私政策公开托管地址。

- 中文：<https://awesome639.github.io/onemore-privacy/>
- English：<https://awesome639.github.io/onemore-privacy/privacy-en.html>

## 核心承诺

**这个应用不收集、不上传任何个人信息。**

- 不采集姓名 / 手机号 / 邮箱 / 通讯录 / 位置 / 相册 / 麦克风
- 不读取设备标识符（IMEI / OAID / MAC）
- 不联网（网络权限仅用于同一 Wi-Fi 下的局域网对战）
- 所有游戏记录只存在用户自己的手机上
- 无广告、无内购、无第三方追踪 SDK

## 适用

HarmonyOS 版「One More」（包名 `com.andrewoscar.onemore`）
